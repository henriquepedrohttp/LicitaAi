# Primeira integração

1. Interface: manter cinco áreas e contexto único da oportunidade; integrar API de requisitos.
2. Documentos: upload, extração por página, OCR e referência verificável; avisar cobertura parcial.
3. Dados: Radar com origem/data, perfil fictício, evidências separadas de declarações, matriz e relatório imprimível.
4. UX/pitch: conferir gabarito no edital original, estados de incerteza e roteiro de 3 minutos.

Pronto para demo: uma jornada completa, revisão registrada, fonte real, ausência de evidência como não verificado e decisão humana. ALEPE é estudo histórico. Dados manuais e pré-processados precisam ser identificados.
